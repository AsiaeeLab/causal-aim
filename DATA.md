# Data acquisition

No datasets ship with this repository. The loaders in `data/*.py` read the standard
public benchmarks once you download them and pass `--use-real-data` with the path
flags shown below. `notebooks/00_setup_and_data.ipynb` walks through every step and
then runs `data/verify_provenance.py`, which loads each dataset through the exact
code path the experiments use and confirms none falls back to a synthetic surrogate.

Put everything under `data/raw/`.

## IHDP

Standard 100-replication "ihdp_npci" setting-B files (Hill 2011 benchmark):

- https://www.fredjo.com/files/ihdp_npci_1-100.train.npz (672 units)
- https://www.fredjo.com/files/ihdp_npci_1-100.test.npz (75 units)

Concatenate train and test along the unit axis into `data/raw/ihdp_npci_1-100.merged.npz`
(keys `x (747,25,100), t, yf, ycf, mu0, mu1`) to recover the full 747-unit sample.
The setup notebook does this merge for you. Pass `--ihdp-npz-path data/raw/ihdp_npci_1-100.merged.npz`;
`tau_true` comes from `mu0/mu1` per replication.

## Twins

Processed Twins benchmark (Louizos et al. 2017; ~11,400 same-sex pairs, both mortality
outcomes observed), distributed with GANITE:

- https://raw.githubusercontent.com/jsyoon0823/GANITE/master/data/Twin_data.csv.gz

The distributed file carries 30 covariates and both potential outcomes but no treatment
column. The setup notebook derives one-year mortality (`y0`, `y1`) and samples a
covariate-dependent treatment with a fixed seed, writing `data/raw/twins.csv`
(columns: 30 covariates, `t`, `y0`, `y1`). Pass `--twins-csv-path data/raw/twins.csv`.

## LaLonde / NSW

Dehejia-Wahba experimental sample from the NBER page https://users.nber.org/~rdehejia/data/ :

- `nswre74_treated.txt` (185 treated)
- `nswre74_control.txt` (260 control)

We use the experimental sample only (n=445); the experimental difference-in-means is the
ground truth. The setup notebook assembles `data/raw/lalonde.csv` (columns
`treat, age, educ, black, hisp, married, nodegree, re74, re75, re78`). Pass
`--lalonde-csv-path data/raw/lalonde.csv`.

## ACIC 2016

Generated by the official competition R package `aciccomp2016`
(github.com/vdorie/aciccomp). The GitHub install path in that repo's README is stale;
install from the tarball's `2016/` subdirectory instead:

```r
# in R, after cloning github.com/vdorie/aciccomp
R CMD INSTALL aciccomp-master/2016
library(aciccomp2016)
sim <- dgp_2016(input_2016, parameters = 7, random.seed = 1)  # the paper's "DGP 7"
```

Export into `data/raw/acic/`: `x.csv` (one-hot the three factor columns to 82 numeric
covariates), `z_dgp7.csv` (treatment), `y_dgp7.csv` (outcome), and
`potential_outcomes_dgp7.csv` (`y0, y1, mu0, mu1, e`). The loader reads the potential
outcomes, so `tau_true` is the true ATE (mean of `y1 - y0`). Pass `--acic-dir data/raw/acic`.

## ACS

California 2018 1-Year person file from the Census Bureau, via folktables:

```python
from folktables import ACSDataSource
ACSDataSource(survey_year="2018", horizon="1-Year", survey="person").get_data(states=["CA"], download=True)
```

folktables writes `data/2018/1-Year/psam_p06.csv`. The semi-synthetic treatment and
outcome are generated by `data/acs_causal.py` from 20 broadly-defined demographic
covariates (structurally missing categorical codes become their own category, so the
complete-case sample supports `n` up to 20,000). No path flag is needed once the
folktables cache is in place.

## Verify

```bash
PYTHONPATH=. python data/verify_provenance.py
```

Prints the source, `n`, `d`, and `tau_true` for each dataset and asserts no
synthetic fallback. Outcomes are standardized during DP measurement by fixed public
constants (recorded in `run_experiments.PUBLIC_Y_STANDARDIZATION`) and reported back in
original units, so RMSE is comparable to the paper.
